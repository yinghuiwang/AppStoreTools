# Web UI Multilingual (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add bilingual (`zh`/`en`) Web UI with Cookie + localStorage persistence, Accept-Language defaults, Jinja/`t()` catalogs, and localized user-facing API messages.

**Architecture:** New `src/asc/web/i18n.py` resolves language per request (Cookie → Accept-Language → `ASC_LANG` → `en`) and loads JSON catalogs from `src/asc/web/locales/`. FastAPI middleware sets `request.state.lang`; `_render` injects `t`, `lang`, and `i18n_catalog` into templates and `window.__I18N`. Language switch writes Cookie + `ASC_LANG` + localStorage then reloads. CLI `src/asc/i18n.py` stays untouched.

**Tech Stack:** Python 3.9+, FastAPI, Jinja2Templates, pytest + TestClient, existing Alpine/htmx (no new i18n libraries).

## Global Constraints

- Spec: `docs/specs/2026-07-29-web-i18n-design.md`
- Supported langs v1: exactly `zh` and `en` (extensible via new JSON + `SUPPORTED_LANGS`)
- Resolve order: Cookie `asc_lang` → `Accept-Language` → env `ASC_LANG` → default `en`
- Persist: Cookie `asc_lang` (`Max-Age=31536000`, `Path=/`, `SameSite=Lax`) + `localStorage['asc_lang']`; Cookie wins on conflict
- Do **not** auto-set Cookie on first paint from Accept-Language
- Do **not** merge Web catalogs into CLI `i18n.py`
- Scope: UI chrome + user-facing API `message`/`detail`; **not** raw task logs / subprocess output
- Missing key: try `en` catalog → else return the key string
- `<html lang>`: `zh` → `zh-CN`, `en` → `en`

Create `src/asc/web/i18n.py`:

```python
from __future__ import annotations

import json
import os
import re
from functools import lru_cache
from pathlib import Path

SUPPORTED_LANGS = frozenset({"zh", "en"})
COOKIE_NAME = "asc_lang"
COOKIE_MAX_AGE = 31536000
_LOCALES_DIR = Path(__file__).parent / "locales"
_ACCEPT_RE = re.compile(r"([a-zA-Z]{2,3}(?:-[a-zA-Z0-9]+)*)")


def normalize_lang(raw: str | None) -> str | None:
    if not raw:
        return None
    s = raw.strip().lower().replace("_", "-")
    if s in ("zh", "zh-cn", "zh-hans", "zh-tw", "zh-hant", "chinese"):
        return "zh"
    if s.startswith("zh"):
        return "zh"
    if s in ("en", "en-us", "en-gb", "english") or s.startswith("en"):
        return "en"
    return None


def resolve_lang(
    *,
    cookie: str | None = None,
    accept_language: str | None = None,
    env_lang: str | None = None,
) -> str:
    for candidate in (cookie,):
        n = normalize_lang(candidate)
        if n in SUPPORTED_LANGS:
            return n
    if accept_language:
        for part in accept_language.split(","):
            token = part.split(";")[0].strip()
            m = _ACCEPT_RE.match(token)
            if not m:
                continue
            n = normalize_lang(m.group(1))
            if n in SUPPORTED_LANGS:
                return n
    env_raw = env_lang if env_lang is not None else os.environ.get("ASC_LANG")
    n = normalize_lang(env_raw)
    if n in SUPPORTED_LANGS:
        return n
    return "en"


@lru_cache(maxsize=8)
def load_catalog(lang: str) -> dict[str, str]:
    code = lang if lang in SUPPORTED_LANGS else "en"
    path = _LOCALES_DIR / f"{code}.json"
    data = json.loads(path.read_text(encoding="utf-8"))
    return {str(k): str(v) for k, v in data.items()}


def t(key: str, lang: str | None = None, **kwargs: object) -> str:
    code = lang if lang in SUPPORTED_LANGS else "en"
    catalog = load_catalog(code)
    text = catalog.get(key)
    if text is None and code != "en":
        text = load_catalog("en").get(key)
    if text is None:
        return key
    if kwargs:
        try:
            return text.format(**kwargs)
        except (KeyError, ValueError):
            return text
    return text


def html_lang(lang: str) -> str:
    return "zh-CN" if lang == "zh" else "en"
```

```python
@router.post("/settings/lang")
async def set_lang(lang: str = _Form("zh")):
    import os
    from fastapi.responses import JSONResponse
    from asc.web.i18n import (
        COOKIE_MAX_AGE,
        COOKIE_NAME,
        SUPPORTED_LANGS,
        normalize_lang,
        t,
    )

    code = normalize_lang(lang)
    if code not in SUPPORTED_LANGS:
        raise HTTPException(status_code=400, detail=t("api.invalid_lang", lang="en"))
    os.environ["ASC_LANG"] = code
    resp = JSONResponse({"ok": True, "lang": code})
    resp.set_cookie(
        COOKIE_NAME,
        code,
        max_age=COOKIE_MAX_AGE,
        path="/",
        samesite="lax",
    )
    return resp
```

```html
<script>
  window.__I18N = {{ i18n_catalog | tojson }};
  window.__ASC_LANG = {{ lang | tojson }};
  window.t = function(key, vars) {
    var s = (window.__I18N && window.__I18N[key]) || key;
    if (vars) {

        s = s.replace(new RegExp('\\{' + k + '\\}', 'g'), vars[k]);

  window.__ascSetLang = function(code) {
    var body = new URLSearchParams();
    body.set('lang', code);

      method: 'POST',
      headers: {'Content-Type': 'application/x-www-form-urlencoded'},
      body: body

      if (!r.ok) throw new Error('fail');
      try { localStorage.setItem('asc_lang', code); } catch (e) {}
      location.reload();

      alert(window.t('lang.switch_failed'));

    var cookieMatch = document.cookie.match(/(?:^|; )asc_lang=([^;]*)/);

    var stored = null;
    try { stored = localStorage.getItem('asc_lang'); } catch (e) {}
    if (cookieLang) {
      try { localStorage.setItem('asc_lang', cookieLang); } catch (e) {}
      return;
    }
    if (stored === 'zh' || stored === 'en') {
      window.__ascSetLang(stored);
    }
  })();
```
